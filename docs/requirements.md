# Requirements

## Functional requirements (what the system must DO)
1. The system shall able to show all the assets details
2. The system shall able to filter the assets based on department
3. The system shall able to allow user to update or edit the assets details by only respective department.
4. The system shall must have a authorisation and authentication method.
5. The system shall able to generate report in excel or pdf.
6. The system shall must be able to logout to clear the session.
7. The system shall able to show a dashboard report.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display all the assets details within 5 seconds.
2. The system shall generate the dashboard report less than 10 seconds.
3. The system shall able to download the generated report in excel or pdf within 10 seconds.
4. The users shall able to login to the system within 2 seconds after correctly authorised.
5. The generated report must have a data range minimum of 1 day.
