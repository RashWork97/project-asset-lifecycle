# Requirements

## Functional requirements (what the system must DO)
1. The system shall able to show all important report columns.
2. The system shall filter the report based on site ID or name.
3. The system shall download the file from the specific url.
4. The system shall save the report file as xlsx format.
5. The system shall open a browser automatically.
5. The system shall close a browser only after all important file has been downloaded.

## Non-functional requirements (how the system must PERFORM)
1. The system shall download all the important file within 1 minutes.
2. The system shall generate a few new columns within 2 seconds.
3. The system shall open the browser within 2 seconds.
