# Requirements

## Functional requirements (what the system must DO)
1.  FR1: The system should be able to predict the lifecycle of an asset.
2.	FR2: The system shall able to filter the assets based on department
3.	FR3: The system shall able to allow user to update or edit the assets details by only respective department.
4.	FR4: The system shall must have an authorisation and authentication method.
5.	FR5: The system shall able to generate report in excel or pdf.
6.	FR6: The system shall must be able to logout to clear the session.
7.	FR7: The system shall able to show a dashboard report.
8.	FR8: The system shall able to show all the assets details


## Non-functional requirements (how the system must PERFORM)
1.  NFR1: The system shall has at least 70% accuracy of lifecycle prediction.
2.	NFR2: The system shall generate the dashboard report less than 10 seconds.
3.	NFR3: The system shall able to download the generated report in excel or pdf within 10 seconds.
4.	NFR4: The users shall able to login to the system within 2 seconds after correctly authorised.
5.	NFR5: The generated report must have a data range minimum of 1 day.
6.	NFR6: The system shall display all the assets details within 5 seconds.
