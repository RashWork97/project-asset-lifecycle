# User Stories

1. 1.	As a user, I want to filter the assets by department name (FR2) so that I can find all my department assets. Acceptance: (1) clearing the filter will show all asset within a company. (2) choosing a department will show the asset in that department only.

2.	As a user, I want to update the latest details for the asset (FR3) so that everyone in the company able to see it. Acceptance: (1) when update the asset, every other company able to see the updated data. (2) update the asset only occur for the asset chosen only.

3.	As a head of department, I want to view the dashboard and report (FR7) so that i can make sure the staff correctly update the details based on the asset. Acceptance: (1) The dashboard shows all the asset but not all details (2) the dashboard able to interact with.

4.	As a general manager, I want to able to download the report (FR5) so that I can show to the Director. Acceptance: (1) the downloaded file must in excel format or pdf. (2) the downloaded report contains all asset in a company.

5.	As general manager, I want the view the lifecycle prediction of every asset (FR1) so that I can prepare the budget for coming year. Acceptance: (1) the asset is showing the prediction about 1 month before a lifecycle ended. (2) the prediction shows for at least same category asset instead of individual.
