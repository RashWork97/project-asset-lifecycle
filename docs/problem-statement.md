# Problem Statement

## Who is affected?
1. Staff
2. Head of department
3. General Manager
4. Director

## What exactly is going wrong?
1. Some of the asset suddenly getting error or problem whenever the user is urgently want to use.
2. Multiple department key in different details for each asset from their respective laptop.
3. The asset details is seperated by company name and must be in Finance department and save in local disk making it unable to be update from another company or department.
4. If there's an update from IT department, a verbal conversation and physical movement is needed to update only a few details.

## Why does it matter?
1. Delay the process or the event that need to be done urgently.
2. Data redundancy can be occured due to each asset is stored in different disk.
3. Cannot view the correct updated asset details when neceessary.
4. Time consuming if movement is needed just to update a few details.

## Problem statement (3 to 5 sentences)
1.  An asset that has been used everyday cause unexpected error making an event such as general meeting interrupted.
2.	Users need to go Finance department that will take up so much time just to update a few details and to avoid data redundancy.
3.	Head of department and general manager cannot correctly audit or observe the latest update for certain asset due to multiple files storing in different laptop.
4.	There is no primary key to ensure that every asset is unique.
5.	Unable to retrieve history for an asset that may have changes or not.
6.	Duplicate list of assets has occurred from multiple department that store it.
